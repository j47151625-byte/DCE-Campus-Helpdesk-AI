# DCE Campus Help Desk AI — Source-Code Demo

This repository contains a small browser-based FAQ chatbot prototype created to accompany the Botpress no-code DCE Campus Help Desk project.

## Files
- `index.html` — complete HTML, CSS, and JavaScript demo in one file.

## Run locally
1. Download `index.html`.
2. Double-click it to open in a modern web browser.
3. Ask one of the sample campus questions or use a quick-question button.

## Important distinction
This is a separate source-code demo, not an export of the original Botpress agent. The Botpress agent remains hosted on Botpress. The demo uses keyword-matched FAQ answers and does not call an AI model or fetch live college data.
